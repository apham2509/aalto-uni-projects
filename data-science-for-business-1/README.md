# Data Science for Business I (30E03000)

Aalto University · 6 ECTS · Autumn 2024 · Group project

## Wolt: how does weather impact delivery times?

End-to-end data science project on real food-delivery data: can weather conditions predict delivery delays? Accurate predictions would let the company optimize courier resources and proactively notify customers of likely delays.

- EDA on autumn 2020 order data joined with weather and courier-partner activity
- Feature engineering and predictive modeling of delivery times under varying weather conditions
- Business recommendations for operations planning

## Files

| File | Description |
|------|-------------|
| `analysis.ipynb` | Full data analysis and modeling notebook |
| `data/orders_autumn_2020.csv` | Order-level delivery data |
| `data/daily_cp_activity_dataset.csv` | Daily courier-partner activity |
| `final_report.pdf` | Final written report |
| `presentation.pptx` | Results presentation |

**Tools:** Python (pandas, scikit-learn, matplotlib)
