# Decision Analytics for Consulting (ISM-E1006)

Aalto University · 6 ECTS · Spring 2025 · Group project · Grade: 5 (Excellent)

## Multi-criteria decision analysis: future-proofing Aalto University

A consulting-style decision analysis exercise: how should Aalto University position itself for alternative future scenarios? The work follows a full decision-analysis process - scenario construction, objectives and attributes, strategic action proposals, elicitation of weights and utilities, and analysis of the resulting recommendations.

## Files

| File | Description |
|------|-------------|
| `decision_exercise_presentation.pptx` | Full walkthrough: scenarios, objectives, weight/utility elicitation, results |
| `consulting_report.docx` | Written consulting report |
| `decision_model.xlsx` | Excel implementation of the decision model |

**Tools:** Multi-criteria decision analysis (MCDA), utility elicitation, Excel modeling
