# Large Scale Data Analysis (ELEC-E5431)

Aalto University · 5 ECTS · Spring 2025 · Individual assignments · Grade: 3 (Good)

Optimization and large-scale machine-learning methods implemented **from scratch in NumPy**, with convergence analysis. Each assignment has the notebook plus a PDF printout.

## Assignments

| Assignment | Files | Topics |
|-----------|-------|--------|
| Assignment 1 | `assignment1.ipynb`, `assignment1_report.pdf` | Gradient descent on quadratic problems, step-size selection via eigenvalues (2/(L+μ)), convergence vs. condition number |
| Homework 2 | `homework2.ipynb`, `homework2_report.pdf` | Lasso regression and regularization paths on the prostate cancer dataset (Stamey et al.), standardization, R² evaluation |
| Homework 3 | `homework3.ipynb`, `homework3_report.pdf` | Elastic Net vs. Lasso vs. OLS, model selection and error analysis |

**Tools:** Python (NumPy, scikit-learn for benchmarking, matplotlib)
