# Machine Learning (CS-C3240)

Aalto University · 5 ECTS · Autumn 2023 · Individual project · Grade: 5 (Excellent)

## Predicting financial system vulnerability in Finland using macroeconomic indicators

Course project combining economics and machine learning: forecasting a vulnerability score for Finland's financial system from key macroeconomic indicators (GDP, inflation rate, CPI), to give policymakers and businesses early signals of potential recessions or financial instability.

- Problem formulation: data points, features, and label design from yearly macroeconomic time series
- Methods: preprocessing, feature selection, Linear Regression and Random Forest regressors, loss functions, and validation strategy
- Two-stage delivery: interim report and final report
